# Getting Started

This repository contains a collection of Rust AI examples demonstrating various machine learning, deep learning, and natural language processing techniques.

## Prerequisites

- [Rust](https://www.rust-lang.org/tools/install) (latest stable version)
- [Cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html) (comes with Rust)

## Running Examples

Each example is a standalone Cargo project located in the `examples/` directory.

```bash
# Navigate to an example directory
cd examples/<example-name>

# Run the example
cargo run
```

### Adding your own data

Most examples read a fixed path relative to their own directory, so the simplest way to try
your own data is to replace the committed file (keeping the same columns). Model-based examples
either use a committed `models/` directory or download it on first run.

## Documentation

This documentation site is built with [Astro Starlight](https://starlight.astro.build/). To run it locally:

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
