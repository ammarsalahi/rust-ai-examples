# استخراج کلیدواژه

## مرور کلی

این مثال استخراج کلیدواژه و عبارت‌های کلیدی مبتنی بر TF-IDF را از اسناد متنی با استفاده از regex و stemming نشان می‌دهد.

## کد منبع

[examples/keyword-extraction/src/main.rs](https://github.com/ammarsalahi/rust-ai-examples/blob/main/examples/keyword-extraction/src/main.rs)

## ساختار پروژه

```text
examples/keyword-extraction/
├── Cargo.toml                 # Crate manifest and dependencies
├── src/
│   └── main.rs                # Whole example: tokenize, TF-IDF, rank (246 lines)
└── documents/                 # Input .txt files (analyzed as one corpus)

    └── cybersecurity.txt
```

| مسیر | نقش |
|------|------|
| `Cargo.toml` | کرت `keyword-extraction` و وابستگی‌های آن را تعریف می‌کند |
| `src/main.rs` | کل خط لوله را روی هر فایل `.txt` یافت‌شده اجرا می‌کند |
| `documents/` | پیکره؛ برای تغییر ورودی، فایل‌های `.txt` را اضافه یا حذف کنید |

## وابستگی‌ها

| کرت | نسخه | هدف |
|-------|---------|---------|
| `regex` | 1 | توکن‌سازی واژه‌ها (با آپاستروف اختیاری) |
| `rust-stemmers` | 1.2 | ریشه‌یابی Porter برای انگلیسی |

## الگوریتم

**TF-IDF** (بسامد واژه-بسامد معکوس سند) یک آمارهٔ عددی است که نشان می‌دهد یک واژه در یک سند درون یک مجموعه یا پیکره چقدر مهم است.

- **TF** (بسامد واژه): اینکه یک واژه چند بار در یک سند ظاهر می‌شود
- **IDF** (بسامد معکوس سند): اینکه یک واژه در میان همهٔ اسناد چقدر یکتا یا کم‌یاب است

## جزئیات پیاده‌سازی

- **الگوریتم**: TF-IDF همراه با ریشه‌یابی Porter
- **وظیفه**: استخراج کلیدواژه/عبارت کلیدی
- **زبان**: انگلیسی
- **N-gramها**: یونی‌گرام‌ها (کلیدواژه‌ها) و ۲ تا ۳ گرم‌ها (عبارت‌های کلیدی)

## اجرای مثال

```bash
cd examples/keyword-extraction
# Add .txt files to documents/ directory
cargo run
```

### ساختارهای داده (خطوط ۲۵ تا ۳۴)

```rust
struct Document {
    name: String,
    tokens: Vec<String>,  // Original tokens (lowercased)
    stems: Vec<String>,   // Stemmed tokens
}

struct RankedItem {
    text: String,
    score: f64,
}
```

### تابع Main - بارگذاری اسناد (خطوط ۳۶ تا ۹۹)

```rust
fn main() -> io::Result<()> {
    let directory = Path::new("documents");
    fs::create_dir_all(directory)?;

    let tokenizer = Regex::new(r"[A-Za-z]+(?:'[A-Za-z]+)?").expect("Invalid regex");

    let stemmer = Stemmer::create(Algorithm::English);

    let mut paths: Vec<_> = fs::read_dir(directory)?
        .filter_map(Result::ok)
        .map(|entry| entry.path())
        .filter(|path| {
            path.is_file()
                && path
                    .extension()
                    .and_then(|ext| ext.to_str())
                    .is_some_and(|ext| ext.eq_ignore_ascii_case("txt"))
        })
        .collect();

    paths.sort();

    if paths.is_empty() {
        println!("No .txt files found in the documents directory.");
        println!("Add text files to ./documents/ and run cargo run.");
        return Ok(());
    }

    let mut documents = Vec::new();

    for path in paths {
        let content = fs::read_to_string(&path)?;

        let mut tokens = Vec::new();
        let mut stems = Vec::new();

        for matched in tokenizer.find_iter(&content) {
            let word = matched.as_str().to_lowercase();

            if word.len() < 2 || STOP_WORDS.contains(&word.as_str()) {
                continue;
            }

            stems.push(stemmer.stem(&word).to_string());
            tokens.push(word);
        }

        if !tokens.is_empty() {
            documents.push(Document {
                name: path
                    .file_name()
                    .unwrap_or_default()
                    .to_string_lossy()
                    .to_string(),
                tokens,
                stems,
            });
        }
    }

    if documents.is_empty() {
        println!("No usable English words found.");
        return Ok(());
    }
```

**خط لولهٔ پردازش اسناد:**
1. **خطوط ۳۸ تا ۴۰**: در صورت نبود، پوشهٔ `documents` را ایجاد می‌کند
2. **خط ۴۲**: توکن‌ساز regex - واژه‌های دارای آپاستروف اختیاری را تطبیق می‌دهد (مثلاً `"don't"`)
3. **خط ۴۴**: ریشه‌یاب Porter برای انگلیسی
4. **خطوط ۴۶ تا ۵۶**: یافتن همهٔ فایل‌های `.txt` در `documents/`
5. **خطوط ۶۶ تا ۹۴**: پردازش هر سند:
   - خواندن کل محتوای فایل
   - توکن‌سازی با regex
   - کوچک‌کردن حروف، فیلتر کلمات توقف و واژه‌های کوتاه (کمتر از ۲ نویسه)
   - ریشه‌یابی هر توکن (الگوریتم Porter)
   - ذخیرهٔ هم توکن‌های اصلی و هم ریشه‌ها
6. **خطوط ۹۶ تا ۹۹**: مدیریت حالت پیکرهٔ خالی

### محاسبهٔ بسامد سند (خطوط ۱۰۱ تا ۱۱۲)

```rust
    // Count how many documents contain each term.
    let mut document_frequency: HashMap<String, usize> = HashMap::new();

    for document in &documents {
        let unique_stems: HashSet<&String> = document.stems.iter().collect();

        for stem in unique_stems {
            *document_frequency.entry(stem.clone()).or_insert(0) += 1;
        }
    }
```

- **خطوط ۱۰۱ تا ۱۱۲**: محاسبهٔ بسامد سند (DF) برای هر ریشه
- **خط ۱۰۵**: استفاده از `HashSet` برای شمارش هر ریشه فقط یک بار در هر سند (DF دودویی)

### TF-IDF هر سند و استخراج کلیدواژه (خطوط ۱۱۴ تا ۱۸۲)

```rust
    let total_documents = documents.len() as f64;

    println!("======================================");
    println!("       RUST KEYWORD EXTRACTION");
    println!("======================================");
    println!("Documents analyzed: {}", documents.len());

    for document in &documents {
        println!("\n======================================");
        println!("Document: {}", document.name);
        println!("======================================");

        let total_terms = document.stems.len() as f64;

        let mut term_frequency: HashMap<String, usize> = HashMap::new();

        for stem in &document.stems {
            *term_frequency.entry(stem.clone()).or_insert(0) += 1;
        }

        // Calculate TF-IDF scores.
        let mut word_scores: HashMap<String, f64> = HashMap::new();

        for (stem, count) in &term_frequency {
            let tf = *count as f64 / total_terms;

            let df = *document_frequency.get(stem).unwrap_or(&0) as f64;

            let idf = ((total_documents + 1.0) / (df + 1.0)).ln() + 1.0;

            word_scores.insert(stem.clone(), tf * idf);
        }
```

**محاسبهٔ TF-IDF (خطوط ۱۳۲ تا ۱۴۳):**
- **TF** = تعداد واژه در سند / کل واژه‌های سند
- **IDF** = ln((N + 1) / (df + 1)) + 1 (IDF هموارشده)
- **TF-IDF** = TF × IDF

```rust
        // Recover the most frequent original spelling for each stem.
        let mut original_counts: HashMap<String, HashMap<String, usize>> = HashMap::new();

        for (word, stem) in document.tokens.iter().zip(&document.stems) {
            *original_counts
                .entry(stem.clone())
                .or_default()
                .entry(word.clone())
                .or_insert(0) += 1;
        }

        let mut keywords: Vec<RankedItem> = word_scores
            .iter()
            .map(|(stem, score)| {
                let word = original_counts
                    .get(stem)
                    .and_then(|counts| counts.iter().max_by_key(|(_, count)| *count))
                    .map(|(word, _)| word.clone())
                    .unwrap_or_else(|| stem.clone());

                RankedItem {
                    text: word,
                    score: *score,
                }
            })
            .collect();

        keywords.sort_by(|a, b| {
            b.score
                .total_cmp(&a.score)
                .then_with(|| a.text.cmp(&b.text))
        });

        println!("\nTop Keywords:");

        for (index, item) in keywords.iter().take(TOP_KEYWORDS).enumerate() {
            println!("{:>2}. {:<30} {:.4}", index + 1, item.text, item.score);
        }
```

**خطوط ۱۴۵ تا ۱۸۲**: 
- نگاشت ریشه‌ها به فراوان‌ترین شکل اصلی واژه (برای نمایش)
- مرتب‌سازی بر اساس امتیاز TF-IDF به‌صورت نزولی، سپس الفبایی
- چاپ ۱۰ کلیدواژهٔ برتر همراه با امتیازها

### استخراج عبارت کلیدی (خطوط ۱۸۴ تا ۲۳۹)

```rust
        // Generate candidate phrases of two and three words.
        let mut phrase_counts: HashMap<String, usize> = HashMap::new();
        let mut phrase_stems: HashMap<String, Vec<String>> = HashMap::new();

        for size in 2..=3 {
            if document.tokens.len() < size {
                continue;
            }

            for start in 0..=(document.tokens.len() - size) {
                let phrase = document.tokens[start..start + size].join(" ");
                let stems = document.stems[start..start + size].to_vec();

                *phrase_counts.entry(phrase.clone()).or_insert(0) += 1;
                phrase_stems.entry(phrase).or_insert(stems);
            }
        }

        let mut phrases = Vec::new();

        for (phrase, count) in &phrase_counts {
            let Some(stems) = phrase_stems.get(phrase) else {
                continue;
            };

            let average_score = stems
                .iter()
                .map(|stem| word_scores.get(stem).copied().unwrap_or(0.0))
                .sum::<f64>()
                / stems.len() as f64;

            let phrase_frequency = *count as f64 / total_terms;

            let score = average_score * (1.0 + phrase_frequency.ln_1p());

            phrases.push(RankedItem {
                text: phrase.clone(),
                score,
            });
        }

        phrases.sort_by(|a, b| {
            b.score
                .total_cmp(&a.score)
                .then_with(|| a.text.cmp(&b.text))
        });

        println!("\nTop Keyphrases:");

        if phrases.is_empty() {
            println!("No phrases found.");
        }

        for (index, item) in phrases.iter().take(TOP_PHRASES).enumerate() {
            println!("{:>2}. {:<40} {:.4}", index + 1, item.text, item.score);
        }
    }

    println!("\nKeyword extraction completed.");

    Ok(())
}
```

**امتیازدهی عبارت کلیدی (خطوط ۱۸۴ تا ۲۲۳):**
- **خطوط ۱۸۸ تا ۲۰۰**: تولید همهٔ ۲-گرم‌ها و ۳-گرم‌ها از دنبالهٔ توکن‌ها
- **خطوط ۲۰۲ تا ۲۲۲**: امتیازدهی به هر عبارت:
  - میانگین TF-IDF ریشه‌های تشکیل‌دهنده
  - تقویت با بسامد عبارت: score × (1 + ln(1 + phrase_freq))
  - `ln_1p()` مقدار ln(1+x) را برای xهای کوچک با دقت محاسبه می‌کند
