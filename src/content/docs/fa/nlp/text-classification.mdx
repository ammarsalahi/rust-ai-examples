# طبقه‌بندی متن

## مرور کلی

این نمونه یک **دسته‌بند متن چندکلاسه** روی یک رمزگذار BERT می‌سازد. به‌جای
دانلود یک مدل از پیش آموزش‌دیده از Hub، یک چک‌پوینت **محلی** BERT را از دیسک
بارگذاری می‌کند (`models/config.json`، `models/model.safetensors`، `models/vocab.txt`).

گردش کار یک خط لوله یادگیری انتقالی *استخراج ویژگی + کاوش خطی* است:

1. ساخت یک توکنایزر WordPiece در کد از `vocab.txt`.
2. اجرای هر جمله از طریق رمزگذار ثابت BERT و برداشتن بردار `[CLS]` به‌عنوان یک
   تعبیه جمله با اندازه ثابت.
3. آموزش یک لایه `Linear` واحد (`hidden_size -> num_classes`) روی آن تعبیه‌ها با
   AdamW و تابع زیان آنتروپی متقاطع.
4. ذخیره سر آموزش‌دیده در `models/classifier_h{hidden}_c{classes}.safetensors`.
5. ورود به یک حلقه تعاملی که متن جدید را طبقه‌بندی می‌کند.

از آنجا که وزن‌های BERT هرگز تغییر نمی‌کنند، آموزش سریع است و تنها تعداد بسیار کمی
پارامتر یاد گرفته می‌شود. این همان روش کلاسیک «کاوش خطی» برای استفاده مجدد از یک
رمزگذار از پیش آموزش‌دیده است.

## ساختار نمونه

```text
examples/text-classification/
├── Cargo.toml                          # Dependencies
├── src/
│   └── main.rs                         # Entire pipeline (1008 lines)
├── data/
│   └── dataset.csv                     # Training data: text,label
└── models/
    ├── config.json                     # BERT architecture (hidden_size 128)
    ├── model.safetensors               # BERT encoder weights
    └── vocab.txt                       # WordPiece vocabulary (30522 tokens)
```

| مسیر | نقش |
|------|------|
| `Cargo.toml` | نام crate با `text-classification` و وابستگی‌های آن |
| `src/main.rs` | همه‌چیز: بررسی فایل‌ها، بارگذاری مجموعه‌داده، توکنایزر، رمزگذار، آموزش، CLI |
| `data/dataset.csv` | نمونه‌های برچسب‌دار، سطر سرصفحه `text,label` |
| `models/config.json` | ابرپارامترهای BERT که توسط `BertConfig` خوانده می‌شوند |
| `models/model.safetensors` | وزن‌های رمزگذار BERT نگاشت‌شده در حافظه |
| `models/vocab.txt` | یک توکن در هر خط؛ برای ساخت توکنایزر WordPiece استفاده می‌شود |
| `models/classifier_h*_c*.safetensors` | پس از نخستین اجرای آموزش **تولید می‌شود** |

:::note
فایل دسته‌بند آموزش‌دیده توسط خود برنامه ساخته می‌شود. حذف آن باعث می‌شود در
اجرای بعدی `cargo run` یک آموزش تازه انجام شود.
:::

## فایل‌های داده و مدل

### `data/dataset.csv`

یک سطر سرصفحه و پس از آن یک نمونه در هر خط. برچسب‌ها رشته‌های دلخواه هستند؛ برنامه
مجموعه یکتا را به‌صورت خودکار کشف می‌کند.

```csv
text,label
Rust is a systems programming language,programming
Python is used for software development,programming
The developer created a REST API,programming
```

### `models/config.json`

BERT محلی یک مدل کوچک است. برنامه این مقادیر را در زمان راه‌اندازی چاپ می‌کند و
`hidden_size` را از آن‌ها می‌خواند:

```json
{
  "hidden_size": 128,
  "intermediate_size": 512,
  "max_position_embeddings": 512,
  "num_attention_heads": 2,
  "num_hidden_layers": 2,
  "model_type": "bert",
  "vocab_size": 30522
}
```

### `models/vocab.txt`

یک فایل متنی ساده با یک توکن در هر خط (واژگان استاندارد BERT شامل `[PAD]`، `[UNK]`،
`[CLS]`، `[SEP]`، ...). باید `30522` ورودی داشته باشد تا با `vocab_size` مطابقت کند.

## مرور گام‌به‌گام کد (خط به خط)

### 1. واردکردن‌ها (خطوط 1-19)

```rust
use anyhow::{Context, Result, anyhow};
use candle_core::{DType, Device, Tensor};
use candle_nn::{
    AdamW, Linear, Module, Optimizer, ParamsAdamW, VarBuilder, VarMap, linear, loss::cross_entropy,
};
use candle_transformers::models::bert::{BertModel, Config as BertConfig};
use rand::seq::SliceRandom;
use serde::Deserialize;
use std::{
    collections::BTreeSet,
    fs,
    io::{self, Write},
    path::{Path, PathBuf},
};
use tokenizers::{
    PaddingParams, PaddingStrategy, Tokenizer, TruncationParams, models::wordpiece::WordPiece,
    normalizers::BertNormalizer, pre_tokenizers::bert::BertPreTokenizer,
    processors::template::TemplateProcessing,
};
```

- **اجزای Candle NN** — `AdamW` و `Optimizer` آموزش را هدایت می‌کنند؛ `Linear` و `Module`
  سر را می‌سازند و اجرا می‌کنند؛ `VarMap`/`VarBuilder` به سر پارامترهای نام‌دار مخصوص
  خودش را می‌دهند؛ `cross_entropy` تابع زیان است؛ `linear` یک کمک‌تابع است که یک
  لایه `Linear` می‌سازد.
- **`BertConfig`** به‌صورت یک نام مستعار وارد می‌شود تا با هیچ چیز دیگری تعارض نداشته باشد.
- **بلوک‌های سازنده `tokenizers`** — `WordPiece`، `BertNormalizer`، `BertPreTokenizer`،
  `TemplateProcessing`، `TruncationParams`، `PaddingParams` به‌صورت دستی در
  `build_tokenizer` سرهم می‌شوند، به‌جای بارگذاری یک `tokenizer.json`.
- **`rand::seq::SliceRandom`** تابع `shuffle` را برای `Vec` فراهم می‌کند.

### 3. پیکربندی آموزش (خطوط 33-43)

```rust
const MAX_LENGTH: usize = 64;

const EPOCHS: usize = 10;

const LEARNING_RATE: f64 = 0.001;

const CONFIDENCE_THRESHOLD: f32 = 0.60;
```

- **`MAX_LENGTH = 64`** — هر ورودی دقیقاً به 64 توکن لایه‌گذاری/برش داده می‌شود. توکنایزر
  با لایه‌گذاری *ثابت* به این طول پیکربندی شده است، بنابراین `encode_text` می‌تواند
  اندازه دقیق را بررسی کند.
- **`EPOCHS = 10`** — تعداد گذرهای کامل روی تعبیه‌های آموزشی.
- **`LEARNING_RATE = 0.001`** — نرخ یادگیری AdamW.
- **`CONFIDENCE_THRESHOLD = 0.60`** — پایین‌تر از این احتمال، حلقه تعاملی یک هشدار
  اطمینان پایین چاپ می‌کند.

### 4. انواع مجموعه‌داده (خطوط 45-69)

```rust
#[derive(Debug, Deserialize, Clone)]
struct Sample {
    text: String,
    label: String,
}

#[derive(Debug, Clone)]
struct LabeledSample {
    text: String,
    label: usize,
}

struct Dataset {
    samples: Vec<LabeledSample>,
    labels: Vec<String>,
}

struct DatasetSplit {
    train: Vec<LabeledSample>,
    validation: Vec<LabeledSample>,
}
```

- **`Sample`** دقیقاً یک سطر CSV را بازتاب می‌دهد (`text`، `label`)، بنابراین `csv`
  می‌تواند مستقیماً `deserialize` کند.
- **`LabeledSample`** همان سطر است با این تفاوت که برچسب از قبل به یک شناسه عددی تبدیل شده است.
- **`Dataset`** نمونه‌ها را به‌همراه فهرست مرتب نام‌های کلاس نگه می‌دارد (شاخص = شناسه کلاس).
- **`DatasetSplit`** دو نیمه آموزش/اعتبارسنجی طبقه‌ای را نگه می‌دارد.

### 6. رمزگذار و دسته‌بند (خطوط 82-102)

```rust
struct Encoder {
    model: BertModel,
    tokenizer: Tokenizer,
    device: Device,
    hidden_size: usize,
}

struct Classifier {
    linear: Linear,
    varmap: VarMap,
    hidden_size: usize,
    num_classes: usize,
}
```

- **`Encoder`** مدل ثابت BERT، توکنایزر آن، دستگاه و عرض تعبیه را در کنار هم نگه می‌دارد.
  `hidden_size` کش می‌شود تا کد پایین‌تر مجبور نباشد پیکربندی را دوباره بخواند.
- **`Classifier`** بخش قابل‌آموزش است. `VarMap` مالک وزن‌ها است تا بتوان آن‌ها را با
  `.save()` / `.load()` ذخیره/بارگذاری کرد؛ `linear` همان لایه واقعی
  `hidden_size -> num_classes` است.

```rust

    let mut classifier = create_classifier(&device, encoder.hidden_size, dataset.labels.len())?;
```

- نام روی دیسک سر آموزش‌دیده را محاسبه می‌کند و یک سر تازه با مقداردهی تصادفی می‌سازد.

```rust

        classifier
            .varmap
            .load(&classifier_path)
            .context("failed to load classifier")?;

        let validation_embeddings = encode_samples(&encoder, &split.validation)?;

            .save(&classifier_path)
```

- **در غیر این صورت**: تقسیم‌های آموزش و اعتبارسنجی را به تعبیه‌های `[CLS]` رمزگذاری کن،
  سر خطی را آموزش بده و آن را ذخیره کن. تعبیه‌ها یک‌بار محاسبه می‌شوند چون رمزگذار ثابت است.

```rust

    Ok(())
}
```

- حلقه خواندن-ارزیابی-چاپ را برای طبقه‌بندی تعاملی آغاز می‌کند.

### 8. `check_required_file` (خطوط 277-293)

```rust
fn check_required_file(path: &str) -> Result<()> {
    let path = Path::new(path);

        return Err(anyhow!(
            "required file not found: {}\n\
             Please place the file at this path.",
            path.display()

    }

    Ok(())
```

- بین «ناموجود» و «وجود دارد اما یک پوشه است» تفاوت می‌گذارد و یک پیام قابل‌اقدام تولید می‌کند.

### 9. `load_dataset` (خطوط 299-368)

```rust
    let mut reader = csv::Reader::from_path(path)
        .with_context(|| format!("failed to open dataset: {}", path.display()))?;

    let mut raw_samples = Vec::<Sample>::new();

    for result in reader.deserialize::<Sample>() {
        let sample = result.context("failed to parse CSV row")?;

        if sample.text.trim().is_empty() { continue; }
        if sample.label.trim().is_empty() { continue; }

        raw_samples.push(sample);
    }
```

- هر سطر را در `Sample` می‌خواند و سطرهایی با متن یا برچسب خالی را بی‌صدا رد می‌کند.

```rust
    let unique_labels: BTreeSet<String> = raw_samples
        .iter()
        .map(|sample| sample.label.trim().to_string())
        .collect();

    let labels: Vec<String> = unique_labels.into_iter().collect();

    if labels.len() < 2 {
        return Err(anyhow!("dataset must contain at least 2 different labels"));
    }
```

- `BTreeSet` یک ترتیب کلاس **قطعی و به‌صورت الفبایی مرتب** می‌دهد، که حیاتی است چون
  شناسه‌های کلاس باید بین اجرای آموزش و اجراهای پیش‌بینی بعدی پایدار بمانند.

```rust
    for sample in raw_samples {
        let label_name = sample.label.trim();

        let label_id = labels
            .iter()
            .position(|label| label == label_name)
            .ok_or_else(|| anyhow!("failed to map label `{}`", label_name))?;

        samples.push(LabeledSample {
            text: sample.text,
            label: label_id,
        });
    }
```

- هر برچسب رشته‌ای را به شاخص آن در `labels` نگاشت می‌کند و `Dataset` نهایی را می‌سازد.

```rust

    let config: BertConfig =
        serde_json::from_str(&config_text).context("failed to parse BERT config.json")?;
```

### 12. `build_tokenizer` (خطوط 450-509)

```rust
    let wordpiece = WordPiece::from_file(&vocab)
        .unk_token("[UNK]".to_string())
        .continuing_subword_prefix("##".to_string())
        .build()
        .map_err(|e| anyhow!("failed to build WordPiece tokenizer: {e}"))?;

    let mut tokenizer = Tokenizer::new(wordpiece);
```

- مدل WordPiece را مستقیماً از `vocab.txt` می‌سازد و از `[UNK]` و `##` دقیقاً همان‌طور
  که BERT استفاده می‌کند بهره می‌برد.

```rust
    let normalizer = BertNormalizer::new(true, true, Some(true), true);
    tokenizer.with_normalizer(Some(normalizer));

    tokenizer.with_pre_tokenizer(Some(BertPreTokenizer));
```

- آرگومان‌های **`BertNormalizer`**: `clean_text`، `handle_chinese_chars`،
  `strip_accents = Some(true)`، `lowercase = true`. این‌ها گام‌های استاندارد
  یکه‌سازی متن در BERT هستند.
- **`BertPreTokenizer`** بر اساس فضای خالی و نشانه‌گذاری تقسیم می‌کند.

```rust
    let processor = TemplateProcessing::builder()
        .try_single("[CLS] $A [SEP]")
        .map_err(|e| anyhow!("failed to configure tokenizer template: {e}"))?
        .special_tokens(vec![("[CLS]".to_string(), 101), ("[SEP]".to_string(), 102)])
        .build()
        .map_err(|e| anyhow!("failed to build tokenizer processor: {e}"))?;

    tokenizer.with_post_processor(Some(processor));
```

- هر دنباله را به‌صورت `[CLS] tokens [SEP]` می‌پیچد و شناسه‌های استاندارد BERT یعنی
  101/102 را تخصیص می‌دهد.

```rust
    tokenizer
        .with_truncation(Some(TruncationParams {
            max_length: MAX_LENGTH,
            ..Default::default()
        }))?;

    tokenizer.with_padding(Some(PaddingParams {
        strategy: PaddingStrategy::Fixed(MAX_LENGTH),
        ..Default::default()
    }));
```

- **برش** تا `MAX_LENGTH = 64`.
- **لایه‌گذاری ثابت** دقیقاً تا 64 توکن. این امر در ترکیب با بررسی طول در `encode_text`،
  تضمین می‌کند که برای هر نمونه یک تنسور ورودی `[1, 64]` داشته باشیم.

### 13. `stratified_split` (خطوط 515-549)

```rust
    let max_label = samples.iter().map(|sample| sample.label).max().unwrap_or(0);

    let mut groups: Vec<Vec<LabeledSample>> = (0..=max_label).map(|_| Vec::new()).collect();

    for sample in samples {
        groups[sample.label].push(sample.clone());
    }
```

- نمونه‌ها را بر اساس کلاس دسته‌بندی می‌کند تا هر کلاس بتواند مستقل تقسیم شود.

```rust
    let mut rng = rand::rng();

    for group in &mut groups {
        group.shuffle(&mut rng);

        let mut train_size = ((group.len() as f32) * train_ratio).round() as usize;

        if group.len() > 1 {
            train_size = train_size.max(1).min(group.len() - 1);
        } else {
            train_size = group.len();
        }

        train.extend_from_slice(&group[..train_size]);
        validation.extend_from_slice(&group[train_size..]);
    }

    train.shuffle(&mut rng);
    validation.shuffle(&mut rng);
```

- هر گروه کلاس را برهم می‌زند، سپس `train_ratio` از آن را به آموزش تخصیص می‌دهد.
- محافظ `max(1).min(len - 1)` تضمین می‌کند تا زمانی که یک کلاس دو عضو یا بیشتر داشته
  باشد، دست‌کم یک نمونه در هر طرف قرار گیرد؛ یک کلاس تک‌عضوی کاملاً به آموزش می‌رود.
- در پایان هر دو بخش برهم زده می‌شوند تا کلاس‌ها در طول آموزش درهم‌آمیخته شوند.

:::caution
`stratified_split` از `rand::rng()` استفاده می‌کند که یک RNG نخ **بدون بذر (seed)** است،
بنابراین تقسیم در هر اجرا متفاوت خواهد بود. اگر به آموزش بازتولیدپذیر نیاز دارید، آن را
با یک `StdRng` بذردار جایگزین کنید (همان‌طور که دیگر نمونه‌های این مخزن انجام می‌دهند).
:::

### 15. `encode_text` (خطوط 575-665)

```rust
    let encoding = encoder
        .tokenizer
        .encode(text, true)
        .map_err(|e| anyhow!("tokenization failed: {e}"))?;

    let ids: Vec<i64> = encoding.get_ids().iter().map(|&id| id as i64).collect();
    let type_ids: Vec<i64> = encoding.get_type_ids().iter().map(|&id| id as i64).collect();
    let attention_mask: Vec<i64> = encoding.get_attention_mask().iter().map(|&id| id as i64).collect();
```

- `encode(text, true)` توکن‌های ویژه را اضافه می‌کند. سه بردار موازی (`input_ids`،
  `token_type_ids`، `attention_mask`) همان چیزهایی هستند که BERT نیاز دارد. شناسه‌های
  `u32` به `i64` ارتقا می‌یابند چون نوع پیش‌فرض تنسور عدد صحیح در Candle `i64` است.

```rust
    if ids.len() != MAX_LENGTH {
        return Err(anyhow!("unexpected tokenized length: {}, expected {}", ids.len(), MAX_LENGTH));
    }

    let input_ids = Tensor::new(ids.as_slice(), &encoder.device)?.unsqueeze(0)?;
    let token_type_ids = Tensor::new(type_ids.as_slice(), &encoder.device)?.unsqueeze(0)?;
    let attention_mask = Tensor::new(attention_mask.as_slice(), &encoder.device)?.unsqueeze(0)?;
```

- قرارداد لایه‌گذاری ثابت اینجا بررسی می‌شود. `unsqueeze(0)` بُعد دسته را اضافه می‌کند
  تا هر تنسور `[1, 64]` شود.

```rust
    let hidden = encoder
        .model
        .forward(&input_ids, &token_type_ids, Some(&attention_mask))
        .context("BERT forward pass failed")?;
```

- گذر کامل رو به جلو. شکل خروجی `[batch=1, seq=64, hidden=128]` است.

```rust
    let sequence = hidden.get(0)?;
    let cls = sequence.get(0)?.contiguous()?;
    let embedding = cls.to_dtype(DType::F32)?.to_vec1::<f32>()?;
```

- `hidden.get(0)` بُعد دسته را حذف می‌کند -> `[64, 128]`؛ `.get(0)` نخستین توکن
  (`[CLS]`) را انتخاب می‌کند -> `[128]`؛ `.contiguous()` آن را به یک بافر فشرده تبدیل
  می‌کند تا `to_vec1` کار کند.
- بردار `[CLS]` همان تعبیه جمله است که به‌عنوان ورودی دسته‌بند استفاده می‌شود.

```rust
    if embedding.len() != encoder.hidden_size {
        return Err(anyhow!("unexpected embedding size: {}, expected {}", embedding.len(), encoder.hidden_size));
    }
```

- محافظ نهایی که عرض تعبیه با `hidden_size` مطابقت دارد.

### 18. `train_classifier` (خطوط 709-811)

```rust
    let mut optimizer = AdamW::new(
        classifier.varmap.all_vars(),
        ParamsAdamW {
            lr: LEARNING_RATE,
            beta1: 0.9,
            beta2: 0.999,
            eps: 1e-8,
            weight_decay: 0.0,
        },
    )?;
```

- AdamW دقیقاً روی متغیرهای سر (`all_vars()`) با ابرپارامترهای پیش‌فرض استاندارد.

```rust
    for epoch in 1..=EPOCHS {
        let mut total_loss = 0.0f64;
        let mut correct = 0usize;

        let mut indices: Vec<usize> = (0..train.len()).collect();
        indices.shuffle(&mut rand::rng());
```

- در هر دوره: بازنشانی معیارها و برهم‌زدن ترتیب نمونه‌ها.

```rust
        for &index in &indices {
            let (embedding, label) = &train[index];

            let input = Tensor::new(embedding.as_slice(), &device)?.reshape((1, classifier.hidden_size))?;
            let target = Tensor::new(&[*label as u32], &device)?;

            let logits = classifier.linear.forward(&input)?;
            let loss = cross_entropy(&logits, &target)?;

            let loss_value = loss.to_scalar::<f32>()?;
            total_loss += loss_value as f64;

            let prediction = argmax_row(&logits)?;
            if prediction == *label {
                correct += 1;
            }

            optimizer.backward_step(&loss)?;
        }
```

- **به‌روزرسانی‌های برخط (نمونه‌به‌نمونه) به سبک SGD.** هر تکرار یک تعبیه را به
  `[1, hidden]` تغییر شکل می‌دهد، لاجیت‌های `[1, classes]` و زیان آنتروپی متقاطع را
  محاسبه می‌کند و بلافاصله `backward_step` را فراخوانی می‌کند، که هم پس‌انتشار *و هم*
  گام بهینه‌ساز را اجرا می‌کند.
- دقت از `argmax` لاجیت‌ها شمرده می‌شود.

```rust
        let train_accuracy = if train.is_empty() { 0.0 } else { correct as f64 / train.len() as f64 };
        let validation_accuracy = evaluate_classifier(classifier, validation)?;
        let average_loss = if train.is_empty() { 0.0 } else { total_loss / train.len() as f64 };

        println!(
            "epoch {:>2}/{:<2} | loss {:.4} | train {:.2}% | validation {:.2}%",
            epoch, EPOCHS, average_loss, train_accuracy * 100.0, validation_accuracy * 100.0,
        );
```

- در هر دوره میانگین زیان و هر دو دقت را چاپ می‌کند تا اثر آموزش قابل‌مشاهده باشد.

## مفاهیم کلیدی

1. **استخراج ویژگی + کاوش خطی** — رمزگذار را ثابت نگه دار، تعبیه‌ها را یک‌بار کش کن،
   یک سر کوچک آموزش بده. بسیار ارزان‌تر از تنظیم دقیق کل ترنسفورمر.
2. **WordPiece ساخته‌شده از `vocab.txt`** — اجزای جداگانه توکنایزر (نرمال‌ساز،
   پیش‌توکنایزر، پس‌پردازشگر، برش، لایه‌گذاری) را نشان می‌دهد، به‌جای پنهان‌کردن آن‌ها
   پشت یک `tokenizer.json`.
3. **ترتیب قطعی برچسب‌ها** — `BTreeSet` یکسان بودن شناسه‌های کلاس را در طول اجراها
   تضمین می‌کند.
4. **انبار پارامتر جداگانه** — `VarMap` سر را به‌صورت مستقل قابل‌ذخیره/بارگذاری می‌کند
   در حالی که وزن‌های BERT در یک نگاشت حافظه فقط‌خواندنی باقی می‌مانند.
5. **نظم شکل‌ها** — لایه‌گذاری ثابت `MAX_LENGTH` به‌همراه بررسی‌های صریح طول، شکل
   تنسورها را قابل‌پیش‌بینی نگه می‌دارد.

## نکات و محدودیت‌ها

- رمزگذار ثابت است: `model.safetensors` هرگز به‌روزرسانی نمی‌شود، بنابراین کیفیت محدود
  به BERT از پیش آموزش‌دیده و بیانگری یک لایه خطی واحد است.
- آموزش از یک نمونه در هر گام بهینه‌ساز (اندازه دسته 1) و یک RNG بدون بذر استفاده
  می‌کند، بنابراین نتایج کاملاً بازتولیدپذیر نیستند. برای پایداری از یک `StdRng` بذردار
  و/یا دسته‌های کوچک استفاده کنید.
- هیچ توقف زودهنگام یا زمان‌بندی نرخ یادگیری وجود ندارد؛ `EPOCHS` و `LEARNING_RATE`
  تنها تنظیم‌کننده‌ها هستند.
- همه ورودی‌ها حتی وقتی بسیار کوتاه‌تر باشند تا 64 توکن لایه‌گذاری می‌شوند، که ساده اما
  پرهزینه است.
