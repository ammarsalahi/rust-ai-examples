# مرجع کتابخانه‌ها

این صفحه اطلاعات مرجع سریعی دربارهٔ کتابخانه‌های اصلی استفاده‌شده در سراسر مثال‌ها ارائه می‌دهد.

## Candle

**مخزن**: [huggingface/candle](https://github.com/huggingface/candle)

یک چارچوب یادگیری ماشین مینیمال برای Rust با تمرکز بر کارایی و سهولت استفاده.

### کرت‌های کلیدی

| کرت | هدف |
|-------|---------|
| `candle-core` | عملیات اصلی تنسور، مدیریت دستگاه، گرادیان خودکار |
| `candle-nn` | ماژول‌های شبکه عصبی (لایه‌ها، تابع‌های فعال‌سازی و غیره) |
| `candle-transformers` | مدل‌های ترنسفورمر آماده (BERT، GPT، T5 و غیره) |
| `candle-examples` | ابزارها و توابع کمکی نمونه |

### الگوهای رایج

```rust
// Device selection
let device = Device::Cpu; // or Device::Cuda, Device::Metal

// Tensor creation
let tensor = Tensor::from_slice(&[1.0, 2.0, 3.0], (3,), &device)?;

// Model loading
let model = Model::load(&model_path, &device)?;
```

### مستندات

- [مستندات API](https://docs.rs/candle-core)
- [مثال‌ها](https://github.com/huggingface/candle/tree/main/candle-examples)

## Linfa

**مخزن**: [rust-ml/linfa](https://github.com/rust-ml/linfa)

یک جعبه‌ابزار برای یادگیری ماشین کلاسیک در Rust، مشابه scikit-learn.

### کرت‌های کلیدی

| کرت | هدف |
|-------|---------|
| `linfa` | صفت‌ها و ساختارهای داده اصلی |
| `linfa-trees` | درخت‌های تصمیم، جنگل‌های تصادفی |
| `linfa-linear` | رگرسیون خطی، رگرسیون لجستیک |
| `linfa-knn` | نزدیک‌ترین همسایه‌های K |
| `linfa-clustering` | K-means، DBSCAN |
| `linfa-preprocessing` | مقیاس‌بندی، کدگذاری، انتخاب ویژگی |

### الگوهای رایج

```rust
// Dataset creation
let (train, test) = dataset.split_with_ratio(0.8);

// Model training
let model = DecisionTree::params()
    .max_depth(Some(5))
    .fit(&train)?;

// Prediction
let predictions = model.predict(&test);

// Evaluation
let cm = predictions.confusion_matrix(&test)?;
```

### مستندات

- [مستندات API](https://docs.rs/linfa)
- [راهنما](https://rust-ml.github.io/linfa/)

## Tokenizers

**مخزن**: [huggingface/tokenizers](https://github.com/huggingface/tokenizers)

توکن‌سازهای سریع و پیشرفته که برای پژوهش و محیط عملیاتی بهینه شده‌اند.

### انواع کلیدی

| نوع | هدف |
|------|---------|
| `Tokenizer` | رابط اصلی توکن‌ساز |
| `Encoding` | خروجی توکن‌سازی‌شده (شناسه‌ها، توکن‌ها، آفست‌ها و غیره) |
| `Model` | مدل توکن‌سازی (BPE، WordPiece و غیره) |

### الگوهای رایج

```rust
// Load tokenizer
let tokenizer = Tokenizer::from_file("tokenizer.json")?;

// Encode text
let encoding = tokenizer.encode("Hello, world!", true)?;

// Access results
let ids = encoding.get_ids();
let tokens = encoding.get_tokens();
```

### مستندات

- [مستندات API](https://docs.rs/tokenizers)
- [اتصال پایتون](https://github.com/huggingface/tokenizers/tree/main/bindings/python)

## Hugging Face Hub

**مخزن**: [huggingface/hf-hub](https://github.com/huggingface/hf-hub)

کلاینت Rust برای Hugging Face Hub.

### توابع کلیدی

| تابع | هدف |
|----------|---------|
| `api.model(id)` | دریافت مخزن مدل |
| `api.dataset(id)` | دریافت مخزن مجموعه‌داده |
| `repo.get(file)` | دانلود یک فایل |
| `repo.get_config()` | دریافت پیکربندی مدل |

### الگوهای رایج

```rust
let api = Api::new()?;
let repo = api.model("bert-base-uncased".to_string());
let config = repo.get_config()?;
let model_file = repo.get("model.safetensors")?;
```

### مستندات

- [مستندات API](https://docs.rs/hf-hub)
- [مستندات Hub](https://huggingface.co/docs/hub)

## Image

**مخزن**: [image-rs/image](https://github.com/image-rs/image)

کتابخانه پردازش تصویر برای Rust.

### انواع کلیدی

| نوع | هدف |
|------|---------|
| `DynamicImage` | شمارشی که همه قالب‌های تصویر را دربر می‌گیرد |
| `ImageBuffer` | بافر تصویر نوع‌دار |
| `Pixel` | صفت پیکسل |

### الگوهای رایج

```rust
// Load image
let img = image::open("path/to/image.png")?;

// Resize
let resized = img.resize_exact(224, 224, FilterType::Triangle);

// Convert to RGB
let rgb = resized.to_rgb8();

// Access pixels
for pixel in rgb.pixels() {
    // pixel is &Rgb<u8>
}
```

### مستندات

- [مستندات API](https://docs.rs/image)

## Clap

**مخزن**: [clap-rs/clap](https://github.com/clap-rs/clap)

تجزیه‌گر آرگومان‌های خط فرمان برای Rust.

### الگوهای رایج

```rust
#[derive(Parser)]
struct Args {
    #[arg(short, long)]
    input: String,
    
    #[arg(short, long, default_value_t = 0.5)]
    threshold: f32,
}

fn main() {
    let args = Args::parse();
    // use args.input, args.threshold
}
```

- [مستندات API](https://docs.rs/clap)
