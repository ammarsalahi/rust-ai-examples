# شروع به کار

این مخزن شامل مجموعه‌ای از مثال‌های هوش مصنوعی با Rust است که تکنیک‌های گوناگون یادگیری ماشین، یادگیری عمیق و پردازش زبان طبیعی را نشان می‌دهد.

## پیش‌نیازها

- [Rust](https://www.rust-lang.org/tools/install) (آخرین نسخه پایدار)
- [Cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html) (همراه با Rust نصب می‌شود)

## اجرای مثال‌ها

هر مثال یک پروژه مستقل Cargo است که در پوشه `examples/` قرار دارد.

```bash
# Navigate to an example directory
cd examples/<example-name>

# Run the example
cargo run
```

| مثال | دسته‌بندی | وضعیت | پیش‌نیازها |

:::note
هر صفحه مثال شامل بخش‌های **ساختار پروژه**، **قالب مجموعه‌داده** و یک
**مرور خط‌به‌خط کد** مخصوص خود است. برای آشنایی با چیدمان کلی از
[نمای کلی پروژه](/fa/introduction/overview/) شروع کنید.
:::

### افزودن داده‌های خودتان

بیشتر مثال‌ها یک مسیر ثابت نسبت به پوشه خودشان را می‌خوانند، بنابراین ساده‌ترین راه برای
آزمودن داده‌های خودتان جایگزین کردن فایل موجود است (با حفظ همان ستون‌ها). مثال‌های مبتنی بر مدل
یا از پوشه `models/` که در مخزن قرار دارد استفاده می‌کنند یا آن را در اجرای نخست دانلود می‌کنند.

## مستندات

این سایت مستندات با [Astro Starlight](https://starlight.astro.build/) ساخته شده است. برای اجرای آن به‌صورت محلی:

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
